## 5. Pemeriksaan Pemanggil RPC `planner_agent_consume_quota`

- Pemanggil yang ditemukan di kode: `my-supabase-project/supabase/functions/planner-agent-run/index.ts:128` — memanggil `planner_agent_consume_quota` dengan argumen lengkap `p_org_id`, `p_tokens`, dan `p_user_id`. Tidak ditemukan pemanggil TypeScript/JS lain yang menghilangkan `p_user_id`.
- **Masalah SQL Overload:**
  - `my-supabase-project/supabase/migrations/20261104220000_planner_phase7_agent.sql:100` mendefinisikan `planner_agent_consume_quota(p_org_id uuid, p_tokens integer)`.
  - `my-supabase-project/supabase/migrations/20261128010000_h_aud_07_shared_rate_limit_and_user_quota.sql:103` menjalankan `CREATE OR REPLACE FUNCTION public.planner_agent_consume_quota(p_org_id uuid, p_tokens integer, p_user_id uuid DEFAULT auth.uid())` **tanpa** `DROP FUNCTION IF EXISTS public.planner_agent_consume_quota(uuid, integer);`.
  - Di PostgreSQL, perbedaan jumlah parameter menciptakan fungsi *overload*, bukan menimpa fungsi lama. Pemanggil RPC dengan 2 argumen `(p_org_id, p_tokens)` tetap bisa mengeksekusi fungsi lama tanpa kuota per pengguna.
